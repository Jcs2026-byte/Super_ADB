# 常见问题（FAQ）

## 连接类

### 为什么连不上设备？
1. 确认设备已开启**开发者选项 → USB 调试**（无线调试请开启"无线调试"）
2. 无线连接需设备与电脑在同一局域网
3. 自研 ADB 直连时，确认设备没有同时被官方 adb server 占用连接槽位（自研模式启动时会自动清理残留 adb 进程）
4. 尝试在环境配置中切换连接模式（自研 ADB / Socket 直连 / 系统 ADB）

### 提示需要授权（AUTH）怎么办？
首次连接设备会弹出授权确认，请在设备屏幕上勾选"始终允许"并确认。自研 ADB 的授权凭证会缓存，多窗口不会重复弹窗。

### 无线调试二维码扫不了？
- 确认电脑与设备在同一网段
- 确认 mDNS（zeroconf）依赖已安装：`pip install zeroconf`
- 可改用配对码连接（adb pair）方式

## 功能类

### URL 编解码在哪里？
主界面 **便捷工具 → 编码工具** 分区，点击「URL编解码」按钮，弹窗支持 UTF-8 百分号编码与解码，可复制结果。

### 抓包没有数据？
- tcpdump 二进制会自动按设备架构推送（arm64/arm）
- 确认已安装抓包证书（证书安装工具）以解密 HTTPS
- 检查 BPF 过滤器是否过滤掉了目标流量

### 安装 APK 失败？
安装失败会自动诊断原因，常见原因：签名冲突、SDK 版本过低、存储空间不足。也可用 APK 分析器先查看包信息。

## 打包类

### 源码运行正常，但打包后启动报错？
- 确认使用各平台 `打包/` 目录下的 spec 文件（不要用硬编码本机绝对路径的旧 spec）
- Windows：`pyinstaller --noconfirm --clean --distpath 打包/dist --workpath 打包/build 打包/Super_ADB.spec`
- Linux：`bash 打包/build_linux.sh --clean`
- macOS：`bash 打包/build_mac_zip.sh`

### 打包体积为什么大？
主要来自 Qt/PySide6 运行库与 scrcpy 投屏二进制（含 adb），属正常现象。spec 已内置 Qt 裁剪逻辑（`打包/裁剪_qt.py`）。

## 平台类

### macOS / Linux 能用自研 ADB 吗？
可以。自研 ADB 为纯 Python 实现，三平台通用，且三平台默认即自研 ADB 模式。

### 三平台的 工具 目录结构一样吗？
一样。三个平台共享同一套 `工具/` 目录结构（`工具/android调试工具/`、`工具/便捷工具/`、`工具/配置/`），方便维护与同步。
