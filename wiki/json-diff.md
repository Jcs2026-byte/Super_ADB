# JSON 对比工具

![JSON对比](.docs/json.png)

## 功能

- 左右两个输入框，支持拖入 .json 文件
- 实时对比两个 JSON 的差异
- 差异高亮显示（新增/删除/修改）
- 导出 HTML 报告，详细展示差异描述

## 使用

1. 打开 JSON 工具对话框
2. 分别将两个 .json 文件拖入左右输入框（或手动粘贴）
3. 自动显示差异对比结果
4. 点击"导出 HTML"保存对比报告

## 导出

- 保存位置：`桌面/Super_ADB/`（与日志导出同目录）
- 文件名格式：`YYYYMMDD_HHMMSS_A文件名_B文件名_对比结果.html`
- HTML 报告包含两个文件的并排展示和差异说明
