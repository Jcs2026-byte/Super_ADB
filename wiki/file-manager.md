# 文件管理器

![文件管理器](docs/文件管理.png)

## 功能

### 浏览与操作
- 连接设备后自动打开 `/sdcard/` 根目录
- 目录树支持展开/折叠，3秒自动刷新当前目录
- 支持上传/下载/删除/重命名/移动文件和目录
- 右键菜单：新建目录、新建文件、授权777、打开所在路径（深度搜索结果）

### 深度搜索
- 工具栏搜索框输入关键词，递归搜索整个 `/sdcard/`
- 搜索结果显示文件名和完整路径
- 右键"打开所在路径"：自动定位并展开到目标文件所在目录，清空搜索框
- 搜索结果中右键"上传文件"已禁用（避免路径歧义）

### 在线编辑与预览
- 双击文本文件（.txt/.xml/.json 等）弹出预览弹窗，可直接编辑
- 编辑后保存自动回传设备，本地缓存到 `桌面/Super_ADB/文件缓存/`
- 双击图片/视频文件使用系统默认工具预览
- 预览弹窗使用统一的弹窗样式（青绿色发光边框）

### 注意事项
- 移动/删除系统文件可能需要 root 权限，失败会弹窗提示
- 切换 ADB 模式时自动停止正在进行的文件管理任务
- 自研模式下 ls 失败会自动重连，但不会反复刷新未打开的目录
