# 系统截图与录屏

## 配置入口

托盘右键菜单 → **系统截图与录屏…**

对话框展示三部分：本软件截图配置、系统截图工具检测、系统录屏（Game Bar）检测。

## 本软件截图

- 可自定义全局热键（默认空 = 不注册热键），点击输入框后按组合键录制，按 Esc 取消
- 点击「测试截屏」立即框选截图，无需热键
- 保存配置时自动检测热键冲突，热键可清空表示不使用

### 截图流程

1. 按下截屏热键（或点击「测试截屏」），屏幕出现半透明遮罩
2. 按住左键拖动框选区域
3. 松开后自动隐藏应用窗口，截取所选区域
4. 弹出预览窗口（画布）+ 底部工具条

### 标注工具

| 工具 | 操作 |
|------|------|
| 选择 | 点击浮层选中，可拖动、调整大小、Delete 删除、Enter 取消选中 |
| 矩形 | 拖动画矩形框，点击后高亮，画完自动恢复 |
| 椭圆 | 拖动画椭圆 |
| 箭头 | 按拖拽方向画箭头 |
| 文字 | 点击画布出现透明输入框，回车确认，双击重新编辑 |
| 颜色 | 红/黄/绿/蓝/白，只影响新创建或当前选中的浮层 |
| 撤销 | 删除最后一个浮层 |

### 其他操作
- 鼠标按住画布空白处拖动整个预览窗口
- 右下角拖拽调整画布大小，图片自动缩放
- 保存：PNG 到 `桌面/Super_ADB/截图/YYYYMMDD_HHMMSS.png`
- 复制：直接复制到剪贴板

## 系统截图工具

- 自动检测系统截图工具（Windows：Win+Shift+S）是否可用，每台电脑可能不同
- 显示系统保存位置（默认 `图片/屏幕截图`），点击路径可直接打开目录

## 录屏（系统 Game Bar）

- 使用系统自带 Game Bar 录屏（Windows：Win+Alt+R），无需在本软件设置
- 自动检测可用性并显示系统保存位置（默认 `视频/捕获`），点击路径可直接打开目录

## 三平台实现

| 平台 | 实现方式 |
|------|----------|
| Windows | RegisterHotKey API（无需管理员权限）；系统功能检测读注册表/系统版本 |
| macOS | PyObjC NSEvent 监听 |
| Linux | python-xlib XGrabKey |
